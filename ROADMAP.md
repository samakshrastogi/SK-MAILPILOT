# SK MailPilot Roadmap

## Level 1 – Must Have
- Smart Email Analytics Dashboard
- Auto Labeling
- Bulk Actions
- Smart Reply Scheduling

## Level 2 – AI Features
- AI Chatbot
- Priority Detection
- Smart Reply Styles
- Follow-up Detection

## Level 3 – Advanced Features
- Multi-Gmail Account Support
- Attachment Intelligence
- Semantic Search
- Email Thread Understanding

## Level 4 – Product Features
- SaaS Model
- Notifications
- Mobile Responsive / PWA
- Activity Logs

## Level 5 – Standout Features
- AI Personal Email Manager
- Voice Commands
- Learning System

## Implementation Note
This roadmap is product-scale. The current codebase now includes the roadmap in-project and the shell
can be iterated from this baseline without losing scope.
